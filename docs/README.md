# — Artificial Cell Laboratory

Copia l'intera cartella ``dentro la cartella`app` del progetto Next.js:

```text
app/
    page.js
    App.jsx
    styles.css
    components/
    data/
    lib/
```

La pagina sarà disponibile all'indirizzo:

```text
http://localhost:3000/
```

Non sono richieste dipendenze aggiuntive oltre a React e Next.js.
